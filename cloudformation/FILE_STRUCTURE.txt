Lifecycle Configuration Flow
================================================================================

1. Code Editor Launch Triggered
   ↓
2. Lifecycle Script Starts (/var/log/lifecycle-config.log)
   ↓
3. Install System Dependencies
   ├── curl, wget
   └── Python 3.10 (if not present)
   ↓
4. Install uv Package Manager
   └── curl -LsSf https://astral.sh/uv/install.sh | sh
   ↓
5. Create Python 3.10 Virtual Environment
   └── python3.10 -m venv ~/medhelm-env
   ↓
6. Install Python Packages
   ├── pip install --upgrade pip setuptools wheel
   ├── pip install --upgrade boto3 sagemaker
   ├── pip install --upgrade "crfm-helm[summarization,medhelm]"
   └── pip install jupyter notebook pandas matplotlib
   ↓
7. Install Google Cloud SDK
   └── Download, extract, install to /root/google-cloud-sdk
   ↓
8. Clone HELM Repository
   └── git clone https://github.com/stanford-crfm/helm.git ~/helm/
   ↓
9. Create Directory Structure
   ├── mkdir ~/benchmark_output
   └── mkdir ~/workshop-notebooks
   ↓
10. Download Benchmark Data (Optional)
    └── gcloud storage rsync gs://crfm-helm-public/medhelm/benchmark_output ~/benchmark_output/
    ↓
11. Create Helper Scripts
    ├── ~/verify_setup.sh
    └── ~/README_MEDHELM.md
    ↓
12. Set Permissions
    └── chown -R sagemaker-user:sagemaker-user ~
    ↓
13. Lifecycle Script Complete ✓
    └── Code Editor Ready for Use!
